# Neige Rouge v2.4.0 — 预订简化（只保留全款）

> 日期：2026-04-16
> 目标：删掉定金选项，预订只有全款付，管理后台预订单独列表

---

## 一、预订流程修改

### 删除的东西
- 删掉"Payer un acompte"定金卡片
- 删掉两个选项的选择界面
- 删掉deposit_per_person相关计算
- 删掉所有arrive/checkout/扣定金逻辑

### 保留的流程
```
客人选日期+时间+人数 → 选菜（必须） → 付全款 → 拿到预订码 → 完成
```

### 前端BookingPage.jsx
- 不再显示两个卡片选择
- 购物车必须有菜品，否则按钮灰掉，提示"Veuillez sélectionner vos plats"
- 只有一个按钮："Payer XX € et réserver"
- 点击后跳转Stancer付全款
- 付款成功后显示预订码

### 后端
- payment_required 始终为 true
- payment_type 始终为 'full'
- amount = 购物车总额
- deposit_amount = 0

## 二、管理后台修改

### 保留两个Tab
```
[Réservations]  [Commandes]
```

只显示预订订单，方便老板一眼找到：


每条预订显示：
- 预订码 + 预订时间 + 人数 + 姓名
- 菜品列表 + 总额
- 电话（方便联系客人）
- 支付状态 🟢 Payé
- 按钮：
  - 未到店：[✅ Client arrivé] [🖨️ Ticket] [📄 Reçu]
  - 已到店：[✅ Terminé] [🖨️ Ticket] [📄 Reçu]

### "Client arrivé"按钮的作用
- 标记预订状态为arrived
- 订单进入后厨大屏制作队列
- 不需要创建新订单（预订本身就是已付款订单）

### Commandes Tab（堂食订单列表）
只显示堂食订单，和现在一样，不变。
