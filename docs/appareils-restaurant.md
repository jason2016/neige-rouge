🔴 **User-Agent 无法确认型号与视口**:
- `X11; Linux x86_64` 是 Chrome 的「桌面版网站」模式,安卓平板以桌面身份出现;
- `Android 10; K` 是 Chrome 的精简 UA:型号固定写成 `K`,安卓版本固定写成 `10`。

前端目前只上报版本(`X-Client-Version`),**不上报视口尺寸**。2026-10-14 的决定:本次不新增上报,
只记录 UA。真实视口的确认要靠店内截图或日后增加的视口上报。

## 前端验收标准(每次都做)

每次雪红前端验收**必须**包含:

1. 两个视口:**1472×920 @2**(厨房屏)与 **1333×800 @1.5**;
2. 同时在屏 **9 张以上**订单,含带选项的菜品;
3. 判据:每张卡**不截断**(`scrollHeight <= clientHeight`)、按钮**可点**(只滚动网格后
   `elementFromPoint` 命中按钮),并且**先在修复前版本上跑出红**,再在新版本上判绿。

缘由:2026-10-14,9 张单同时在屏时卡片被压扁,选项和按钮全部不可见,厨房屏不可用。
此前的验收只用 1–3 张单和 1280×800,结构上就看不见这个缺陷(修复 `e4cd9ac`)。
